# 弹跳小球：设计到交付演示

## 需求
制作一个可无限循环的矢量小动画：蓝色小球落下、接触地面时压扁，再弹起。阴影随高度变化。画面可缩放，支持减少动态效果的系统偏好。

## 文件
- `ball.svg`：可独立打开和复用的矢量动画。
- `index.html`：带暂停/播放按钮的演示页面。

## 验收
- 小球循环弹跳，落地时有挤压效果。
- 阴影随小球接近地面变深、变宽。
- 按钮可以暂停和继续动画。
- 小屏幕可完整显示；减少动态效果模式默认静止。

需求 → 分支制作 → 浏览器预览 → 验收 → 合并。
