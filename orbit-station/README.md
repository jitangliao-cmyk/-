# 轨道能量站

基于 Sam Herbert 的 [SVG-Loaders](https://github.com/SamHerbert/SVG-Loaders) 中 [three-dots.svg](https://github.com/SamHerbert/SVG-Loaders/blob/master/svg-loaders/three-dots.svg) 改编。保留圆点半径及透明度脉冲，周期由 0.8 秒调整为 1.6 秒，配色改为可切换主题。

新增三重轨道、卫星与飞行器、能量波、扫描光束、星光、核心和暂停／速度／主题控件。动画为 SVG，无外部脚本依赖。系统启用减少动态效果时默认暂停。

打开 index.html 即可使用。原项目版权及 MIT 许可完整保留于 LICENSE-SVG-Loaders.txt。原作者 Sam Herbert，Copyright (c) 2014。
